# 比例测量（P1）实现与验证

## 功能定义

以已精修的标准图为参考，测量待处理模特图的头身比、肩宽占比、腰肩比、胯腰比、腿长占比，输出差异对比与调整建议。**P1 阶段只测量分析，不自动液化**——建议供修图师人工参考执行。

## 算法（proportion-core.js）

### 前景分割（白底假设 + 洪水填充收敛）
1. 白底候选：亮度 ≥ 四角中位数-18 且饱和度 < 0.3（自适应阈值）。
2. 洪水填充：从四角种子扩散，只保留与四角连通的背景——**白衣与背景同色但不连通时正确保留**（真机验证：灰白家居服图白衣从误判 11.6% 修正为 27.4% 前景）。
3. 连通域清理：保留最大域（人体主体）。
4. **贴边检测**：前景与左右边+顶边的接触比例 > 12% 判定"白底不可分离"（主体撑满画面），拒绝测量并提示用户提供留有空隙的图。脚底贴底边是正常姿态不计入。

### 关键点（行宽轮廓启发式）
行级左右边界 → 宽度剖面 → 关键点：
- 头宽：身高前 12% 窗口内最大宽度
- 头长：头宽 × 1.35（人类学均值，比"宽度跳升找下巴"更稳）
- 肩线：下巴检测点下 18% 身高内宽度峰值
- 腰：肩下 15%~48% 身高窗口内宽度极小值
- 胯：腰下 70% 窗口内宽度极大值（需 > 腰宽 1.05 倍，否则置无效——衣服遮挡常见）
- 脚底：最后一条有内容的行

### 比例与对比
- 指标：头身比（身高/头长）、肩宽/身高、腰肩比、胯腰比、腿长占比（胯/腰到脚底 / 身高）
- 常规范围校验：头身比 6.5~8.5、肩宽比 0.20~0.28、腰肩比 0.6~0.85、胯腰比 1.0~1.4、腿占比 0.45~0.58（超出标 ⚠）
- 姿态可比性：两图轮廓宽高比差 > 25% 时明确警告"姿态/透视不同，建议仅供参考"
- 建议：差异超阈值才生成（头身比 ±0.4、肩宽比 ±0.02、腿占比 ±0.015），delta 是百分比方向提示而非执行参数

### 已知边界（不虚报）
- 白底棚拍假设；背景复杂/灰底不可靠
- 主体贴满画面时明确拒绝而非硬测
- 轮廓启发式不等于骨骼关键点：跨包、帽子、蓬裙会改变宽度剖面（作为轮廓的一部分被如实测量）
- 不声称与骨骼级姿态估计等价

## 验证

### 自动回归（scripts/test-proportion-core.cjs，8 项全过）
分割、关键点顺序、头身比范围、同人形零差异、头大触发头部建议、肩宽差异触发肩部建议、非人形拒绝、确定性。

### 真实图片验证（用户提供的两张棚拍图）
- 图1（砖红上衣+跨包）：置信度 95%，覆盖率 50.9%，轮廓目检完整（包、帽、衣全保留）
- 图2（灰白家居服）：洪水填充修复白衣误判；贴边检测确认不可分离场景处理正确
- 对比输出：5 项指标差异 + 3 条建议 + 姿态警告，全部合理

## 接线

- `src/modules.json`：`proportion` 卡（760×580）
- `src/renderer/proportion.html`：复用肤色卡的 skinInspectDocument/skinReadMask/skinReadImage IPC（只读不写）
- 输出：卡片内表格对比 + 常规范围警告 + 建议列表；无 PS 写回（P1 边界）
