# 来福 Life-ai 6.0.39

## 商业精修模块完整落地（PRD 14 项 + 组卡管理）

控制台新增「商业精修」分组（自动修图旁），15 张功能卡：

| 功能 | 说明 |
| --- | --- |
| 批量改色 | SKU 原生调色工程（此前版本已有） |
| 色调统一 | 标准图商品色调批量对齐，商品标准色保护 |
| 肤色统一 | 皮肤规则分割+Lab 分位数匹配，原生调整层可编辑 |
| 比例测量 | 头身比/肩宽/腿占比测量+建议+形变应用 |
| 白底净化 | 照明场归一，灰白底→目标白，接触阴影保留 |
| 边缘净化 | 抠图白边/黑边/溢色收敛，毛发安全 |
| 去油光 | 双层均值高光压制，镜面保护、纹理保留 |
| 瑕疵清理 | 形态学检测+Inpainting，大瑕疵域填充 |
| 智能阴影 | 接触阴影+方向投影，商品本体保护，独立透明层 |
| 褶皱优化 | 多尺度分解：低频暗斑收敛+高频布纹保留 |
| 皮肤精修 | 色斑均匀+瑕疵修复+纹理保留（防塑料感） |
| 材质增强 | 高频细节放大+强边缘保护（防光晕） |
| 产品对齐 | 多图层等比对齐（禁拉伸），几何变换一步撤销 |
| 精修质检 | 6 项只读交付检查（尺寸/背景/边缘/曝光/清晰度/越界） |
| 图层拆分 | 透明分层（此前版本已有） |

全部本地算法，无 AI 调用、无网络依赖；结果均为独立图层或可编辑调整层，原组保留，PS 历史一步撤销；算法异常触发事务回滚。
