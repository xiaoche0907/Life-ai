# 肤色统一（P0）实现与验证

## 功能定义

以用户提供的已精修标准图为参考，自动识别皮肤区域，计算源图与参考图的肤色分布差异，在当前 PS 文档所选蒙版组内创建带皮肤灰度蒙版的可编辑原生调整层。全部本地计算，无 AI 调用、无网络上传。

## 算法结构

### 皮肤分割（skinmatch-core.js segmentSkin）
- YCbCr（BT.601）肤色带 + 收紧带 + Lab 肤色带三级规则，输出逐像素概率（1.0 / 0.85 / 0.7 / 0）。
- 4 邻接连通域清理：小于面积阈值的域视为噪点清除。
- 输出置信度（平均概率 × 保留占比）。**规则分割不是语义 AI**：浅色布料、木纹、部分背景可能误判；置信度 < 55% 时 UI 明确建议手动框选修正。

### 统计与匹配（skinStats / fitSkinModel）
- 皮肤区域内 L/a/b 直方图分位数（L 取 p05/p25/p50/p75/p95，a/b 取 p25/p50/p75）。
- 匹配模型：L 三点软对齐（tanh 限幅，防高光变灰、阴影变脏）+ a/b 中位平移软限幅。
- 强度参数：肤色匹配（colorStrength）、明暗匹配（lightStrength）独立控制。
- 「只调色相」模式（hueOnly）：光照差异明显时不匹配明度。

### 原生配方（buildNativeRecipe）
- 输出两层（复用 recolor-native.js 六类描述符与校验）：
  1. 肤色明度—曲线（luminosity 混合，1 通道）
  2. 肤色颜色—RGB曲线（color 混合，4 通道：合成恒等 + RGB）
- 源皮肤亮度 p05-p95 区间之外强制恒等：保护背景、头发、暗部。
- strength=0 时最大偏差为 0（近似恒等，回归验证）。
