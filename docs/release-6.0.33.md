# 来福 Life-ai 6.0.33

## 商业精修模块（本轮新增，收在控制台「商业精修」组卡内）

- **肤色统一**：以已精修标准图为参考，自动识别皮肤（规则分割，非AI），Lab 分位数匹配，生成带皮肤灰度蒙版的原生调整层（明度曲线+颜色曲线），可继续编辑。支持匹配强度/明暗强度/只调色相参数。大图蒙版分块转换，修复栈溢出。
- **比例测量 + 应用**：白底轮廓分割（四角种子洪水填充）测量头身比/肩宽/腰肩比/胯腰比/腿占比，与参考图对比输出差异与建议；建议自动填入参数滑块，一键生成形变图层写回 PS（原图层保留，可开关对比）。主体贴满画面时明确拒绝并提示。
- **白底净化**：不均匀灰白底自动归一到目标白（照明场归一），商品像素不受影响，接触阴影可选保留，背景均匀度实时评估；结果为独立净化图层。
- **精修质检（基础版）**：交付前只读检查——尺寸、背景纯度、主体越界、边缘溢色、曝光极值、清晰度，按严重程度排列，问题附位置。不修改任何图层。
- 控制台新增「商业精修」分组（位于自动修图旁），后续精修功能自动归组。
