# Life-ai 测试版 6.0.20

本版合并官方「橙AIper」6.0.20 全部新功能，保持来福品牌与青色主题不变。

## 新功能

### 软件更新卡

- 设置新增「软件更新」卡片：手动检查、查看更新说明、下载安装新版。
- 「自动检查」「自动下载」两个开关**默认关闭**；提示词库自动更新开关自动沿用你原来的设置。
- ⚠ 提醒：内置更新源指向官方渠道。**请保持两个自动开关关闭**——开启会下载官方「橙AIper」安装包覆盖来福品牌。升级来福请照仓库 `docs/HOW-TO-MERGE-UPSTREAM.md` 手动合并。

### 提示词库云端更新

- 提示词库支持从官方源检查/拉取新版本，本地留存同步底账，防重复、可追溯。
- 只更新提示词内容，不影响品牌与配置。

### 拼音搜索

- 提示词库等长列表支持拼音首字母检索。

### 新出厂提示词 9 套

- 爆乳加强、去皱、浓妆、NG脸修正、NG肤修正、道具材质、透肉丝袜、泳裤、大腿挤压。

### 墨墨（momo）渠道

- 生图侧渠道唤醒、对话侧新增墨墨，老配置自动补齐槽位，填 Key 即可用。

## 修复与改进

- **高分屏布局修复**：2560×1600@150% 等缩放场景「默认布局乱、卡牌互相压住」的问题；没手动改过的布局自动重算。
- **对话架构调整**：「默认渠道/模型」并入「其它功能的模型」；语料与模型解耦，AI 对话、转 JSON 可各自指定语料；原对话模型配置自动迁移，不会被静默换掉。
- Photoshop 桥接 1.0.59 → 1.0.66：新增批量回图、工具预设导入、批处理等命令；安装脚本文案改从 manifest 读取。
- 卡牌置顶、前台抢回、切程序焦点回归等一批窗口管理修复。
- 错误提示、日志、密钥保管等底层改进。

## 升级须知

- **数据零迁移**：`documents\橙子` 数据目录、配置、对话历史、提示词库全部原样沿用，覆盖安装即可。
- 对话系统提示词改由「其它功能的模型 → AI 对话 → 语料」下拉决定；想让「来福」人设生效，把语料挑成「来福」。
- PS 桥接首次启动会提示更新插件，按提示操作即可（更新前保存作品、退出 Photoshop）。
- 入库提示：角色结构恢复双内置角色——「来福」人设（可见）+「来福语料（阉割版）」（工法语料，文本不出主进程）。

## 安装与使用

下载本发布附带的 Windows x64 安装包并安装。插件更新前请保存作品，退出 Photoshop，保持来福运行，等待提示安装完成后再打开 PS。
