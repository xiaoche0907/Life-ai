# 来福 6.0.42

这版修复了旧版升级后 Photoshop 桥接缺少选框工具预设、切换选框比例时报错的问题。

- 来福启动时会核对桥接文件。即使版本号相同，缺少预设或其他随包文件也会触发修复。
- Photoshop 正在运行时，请保存文档并完全退出。来福会等待退出后继续修复。Windows 弹出管理员确认时，请允许更新机器级插件。修复完成后，重新打开 Photoshop。
- 修复会清理旧版来福桥接的重复副本，保留其他 Photoshop 插件。若替换过程中失败，会尝试恢复原来的桥接和注册信息。

可从 GitHub 下载 Windows 安装包，或在来福的「更新」卡检查升级。桥接安装回归已覆盖旧版残留、同版本缺少预设、等待 Photoshop 退出、失败恢复和拒绝管理员授权。
