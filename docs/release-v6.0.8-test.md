# Life-ai 测试版 6.0.8

本版优化 Photoshop 桥接更新，并修复模型列表获取的网络兼容问题。

## Photoshop 插件更新

- 设置新增“清理旧版并安装新版”入口。
- Photoshop 运行时等待退出；保存作品、完全退出 PS 并保持来福运行后，自动继续替换。
- 清理机器级及当前用户级的同 ID 旧插件目录、重复登记，完整替换新版文件。
- 安装失败时尝试恢复原文件与登记，保留其他插件。
- 系统目录权限不足时显示“授权清理并安装新版”，按系统提示授权后重试。
- 检测到 PS 仍运行旧桥接时自动安排更新。

## 模型列表获取

- 使用 Electron 网络栈获取模型列表，以兼容系统代理。
- 统一处理 Base URL、`/v1` 及完整模型列表地址。
- 增加超时处理及 Key、域名、代理、证书、接口错误提示。

## 源码开发

- 新增 `npm run dev`：界面文件保存后自动刷新，主进程代码保存后自动重启。
- 开发版与安装版沿用相同配置及单实例限制，请勿同时运行。
- PS 插件自身更新仍需要退出 Photoshop 后加载。

## 安装与使用

下载本发布附带的 Windows x64 安装包并安装。插件更新前请保存作品，退出 Photoshop，保持来福运行，等待提示安装完成后再打开 PS。

## 验证

- 146 个源码、JSON 及界面文件检查通过。
- 桥接退出等待、自动继续、完整替换、重复清理、失败回滚、登记保留及权限提示回归测试通过。
- 模型请求地址、鉴权传递、响应解析及错误分类测试通过。
- 用户已完成当前开发版使用测试；不同 Photoshop 版本仍可能存在环境差异。
