# 来福 Life-ai 6.0.40

- Photoshop 新增可停靠的「服装精修」面板。圈选区域后，点击去褶皱、车缝线、边缘、面料或印花等能力，生成后贴回独立图层。默认 Auto 比例和 2K 分辨率，可自行调整，模型跟随来福的「生图模式」。
- 桥接升级至 v75。已在 Photoshop 实机确认右侧折叠栏显示来福小狗图标，点击可展开「服装精修」。
- 来福控制台隐藏滚动条，保留滚轮操作。窗口缩窄时入口自动换列，修复了卡片重叠和「瑕疵清理」图标缺失。

安装后重新打开来福和 Photoshop，打开「增效工具 → 来福桥接 → 服装精修」。如果 Photoshop 未加载新版插件，可在来福设置中重新安装 Photoshop 插件，再重启 Photoshop。
