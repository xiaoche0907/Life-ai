# 来福 6.0.41

- Photoshop 侧栏和来福卡片的「服装精修」统一使用原有生图流程。框选后点击精修能力会打开「生成进度」，可查看输入、任务状态和生成结果。
- 开启自动回传时，精修结果使用原有的分组与蒙版结构贴回。关闭自动回传或贴回失败时，结果会保留在「生成进度」，可从那里手动贴回。
- 精修去掉了自动附加的白色参考图。用户在「参考图」卡主动添加的图仍按正常生图规则发送。
- 随包 Photoshop 桥接更新至 v77，用于显示生成完成和待贴回状态。安装新版后重启 Photoshop 加载桥接更新。

共享生图调用、进度登记、贴回状态和控制台布局已通过自动化回归。真实生图渠道未在本次发布验证中调用。
